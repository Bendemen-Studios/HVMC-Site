Hoe join ik de server?

Let op: je moet al toegevoegd zijn aan de whitelist voordat je kunt spelen.

Playstation / Xbox / Switch

Je hebt een Microsoft-account en een online abonnement van de betreffende console nodig.

Stap 1 — Download MC Server Connector: Android · iOS

Stap 2 — Console en telefoon op hetzelfde wifi-netwerk.
Stap 3 — IP: play.hvmc.nl · Poort: 19132
Stap 4 — Kijk de advertentie.
Stap 5 — Kijk bij vrienden/LAN-games op je console.
Stap 6 — Spelen maar!

Mobiel / Tablet

Ga naar Servers → Voeg een server toe → IP play.hvmc.nl → poort 19132 → Server toevoegen → Spelen.

Computer — Java Edition

Minimaal versie 1.21.11. Multiplayer → Add Server. Naam: HVMC · IP: play.hvmc.nl → Done → Join Server.

Computer — Windows Edition

Servers → Voeg een server toe → IP play.hvmc.nl → poort 19132 → Server toevoegen → Spelen.
